# Article Pattern Classifier

TF-IDF text classification using logistic regression and Naive Bayes, with held-out metrics, a confusion matrix, interactive text scoring, influential terms, and error analysis.

The bundled corpus is synthetic. Upload a legitimately obtained CSV with `text`/`article` and binary `label`/`class` columns.

```bash
pip install -r requirements.txt
streamlit run app.py
```

This is a dataset-label classifier—not a truth detector or fact checker.
